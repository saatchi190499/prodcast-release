# ProdCast v0.5.0 — кандидат на выпуск

Общий комплект обновляет App, Agent, AI и Worker относительно v0.4. Точные исходные коммиты, версии сборок и контрольные суммы будут зафиксированы в `plans/v0.5.0.json` и в манифесте готового Complete ZIP.

## Изменения

- App: типы и варианты значений свойств, категории и их доступность в разделах; обновлённые страницы настроек и оборудования; работа с событиями и заполнение из источников.
- App: настройки LDAP/LDAPS, фильтрация по группам и актуализация Django Admin.
- App: управление журналами и отображение занимаемого ими места, изменения аудита и хранения истории расчётов.
- App: поддержка Oracle как внешнего источника данных.
- AI: генерация и проверка вызовов плагинов workflow на основе переданных контрактов исходного кода.
- Agent: поддержка обхода блоков workflow и согласованные зависимости.
- Worker: согласованные зависимости для стека с Oracle-источниками.
- Выпуск: общий черновик, проверка целостности пакетов и отдельная публикация проверенного комплекта. Исправлен поиск GitHub drafts; перед тегами компонентов выполняется `Prepare release draft`.

## Состав и обновление

Manager 0.3.3 и офлайн-зависимости ОС/БД наследуются из v0.4. Дополнительные Ollama-компоненты используются из v0.4 по прежней контрольной сумме. Репозиторий prodcast-license не изменяется; базовый комплект v0.4 не содержит отдельного License-пакета.

Перед обновлением сохраняют резервные копии БД, файлов и конфигурации площадки. Используют инструкцию из нового комплекта и действующие сертификаты и ключи. Необходимые миграции выполняют до запуска обновлённых Workers. Возврат старых образов не отменяет миграции базы данных.

## Статус проверки

Сборки компонентов включают проверки упакованных бинарных файлов и контейнеров. Общая сборка проверяет происхождение и контрольные суммы файлов и сохраняет формат Manager schema 3.

Проверка установки/обновления именно этого комплекта на VM ещё не выполнена. Результаты испытаний базового v0.4 не считаются испытаниями v0.5.0. До отдельного подтверждения совместимости комплект остаётся черновиком, стабильная версия не публикуется.
