# Статус сборки 0.3.1 / ProdCast 0.4 Offline

По запросу владельца новая сборка подготовлена без прогона установки и автоматических тестов. RHEL 9, SELinux, firewalld, перезагрузка и новый App/Worker v0.3.1-rc.1 требуют приёмки позже. Ниже сохранена история старых версий, которая не подтверждает текущую сборку.

# Manager 0.2.5 — границы проверки

Проверены переключение русского/английского интерфейса без потери введённых данных, динамические поля для 1–16 Workers, параметры PostgreSQL/Redis и служебные доступы для выбранного количества, отключённый AI с пустым адресом и его позднее добавление через обновление того же релиза. Проверены сохранение идентичности старой площадки, сертификатов и паролей, отсутствие установки GPU-драйверов даже при старом флаге профиля.

Количество успешных автоматических тестов записано в VALIDATION.json. Проверяются исходники, PowerShell-синтаксис и упакованные GUI/CLI. Существующие проверки активации, SSH, PFX и восстановления операций сохранены.

24 сентября 2026 года исходный Manager 0.2.3 успешно повторно развернул релиз v0.3.0-rc.1 на production через «Обновить», сохранив данные. Проверены App, DB, два Workers, AI и существующая офлайн-лицензия. ОС стенда: Ubuntu 26.04 и Windows Server 2025. Проверены HTTPS с доверием сертификату на ПК, вход/выход администратора и восстановление резервной копии БД в отдельную временную базу (48 таблиц).

Сборка 0.2.4 исправляет выявленные при аудите ошибки: падение CLI при русском выводе в Windows-1252 и жёсткое ожидание трёх потребителей очередей при обновлении. Теперь проверяются все настроенные Workers и потребитель очереди App. Добавлены четыре регрессионных теста; всего 235 успешных тестов. Верифицированы упакованные GUI/CLI. Полный серверный прогон именно 0.2.4 ещё не выполнен.

Первичная установка на чистые Ubuntu 22.04 / Windows Server 2022 в этом прогоне не проверялась. Переустановка существующего стека не проверяет загрузку зависимостей на пустые ОС, установку Docker/Python с нуля и поведение после перезагрузки. Установка третьего и последующих Workers, GPU-инференс и все остальные поддерживаемые ОС требуют отдельной приёмки. Тесты с имитацией SSH не подтверждают реальное развёртывание VM.

Версия 0.2.5 добавляет восстановление контейнеров и остановленных/отсутствующих Workers из установленного релиза, проверку работоспособности при повторе шагов, повтор частичной установки Docker/Compose и запрет создавать пустую БД при потере прежних данных. Проверены имитации отказов, сохранение содержимого каталогов данных, продолжение той же операции после исправления прав и PowerShell-функции восстановления с изолированными системными вызовами. Полного серверного прогона 0.2.5 не было; актуальное число тестов — в VALIDATION.json.
