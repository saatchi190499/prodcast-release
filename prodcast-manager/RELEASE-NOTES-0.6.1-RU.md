# ProdCast Manager 0.6.1

Локальный исправляющий релиз Manager, собранный на базе Manager 0.6.

- Добавлена кнопка «Остановить предыдущую операцию».
- Операция, завершившаяся ошибкой, больше не блокирует запуск исправленного релиза.
- Журналы ошибочных операций сохраняются в `history`.
- Остановка освобождает владельца операции на App, DB и Workers без удаления vault, бэкапов и серверных журналов.
- Сохранены механизмы Manager 0.6: добавление Workers, стабильная топология профиля и совместимость Worker-пакетов.

Перед запуском сохраните папку площадки и vault. Если удалённая VM всё ещё удерживает старый operation ID, откройте вкладку установки и обновления и нажмите «Остановить предыдущую операцию».
