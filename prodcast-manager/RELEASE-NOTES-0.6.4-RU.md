# Manager 0.6.4

Новые пакеты Worker объявляют поддержку режима локальной учётной записи и расчётов без тайм-аута. Manager сохраняет эти настройки в site.json и проверяет соответствующий режим готовности. Запрет дочерних процессов остаётся в Worker. Старые пакеты используют прежний режим AppContainer. Полный релиз с новой политикой требует Manager 0.6.4.

В репозиториях компонентов также сохранены доступ Agent к локальным файлам, XlsxWriter, исправления шаблонов Graphics и совместимая политика стилей CSP. Обновление исходников не меняет уже установленные production-серверы.
