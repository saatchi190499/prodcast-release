# ProdCast Manager 0.6.3

Самостоятельный EXE для Windows; предыдущий выпущенный Manager — 0.6.2. Профили и журналы остаются в `prodcast-data`. Исходники в бинарный релиз не включены. Вложены существующие PDF-руководства EN/RU v0.6; обновлённый формат моделей описан ниже.

Исправлено развёртывание AI Documents: полная добавочная схема библиотеки в `prodcast_ai`, непривилегированный владелец таблиц, включённый RAG, модель `qwen3-embedding:0.6b`, проверка размерности 1024 и постоянный каталог `/opt/prodcast-manager/ai-data/documents`. Проверяется запрос библиотеки напрямую и из App. Старые сохранённые результаты установки AI не препятствуют исправлению.

## Простой ZIP моделей

В архиве ровно два файла:

```
Qwen3-4B-Instruct-Q4_K_M.gguf
Qwen3-Embedding-0.6B-Q8_0.gguf
```

Выберите ZIP в поле моделей AI. ZIP компонентов Ollama по-прежнему выбирается отдельно: в нём находится проверенная конфигурация и шаблон чат-модели. Конфигурацию embedding Manager добавляет сам. В ZIP моделей не нужны manifest и файлы с хэшами в именах. Размер и SHA256 обоих GGUF проверяются по содержимому; переименование не обходит проверку. Поддерживается ZIP64. Внутренние файлы Ollama с хэшами в именах создаются при установке автоматически, без скачивания моделей в офлайн-сети.

Прежний ZIP публичного кэша Ollama также поддерживается. Одиночный GGUF чат-модели подходит для старого профиля, только если embedding уже установлен; иначе выводится понятная ошибка без отключения поиска документов.

## Применение

Сохраните существующий `prodcast-data` и vault. Выберите тот же complete-пакет стека, который установлен, его проверенный хэш manifest, совместимый ZIP компонентов Ollama и новый ZIP из двух GGUF. Нажмите **«Повторить AI»**. Будет исправлена схема на DB и пересоздан AI; App и Workers не обновляются и не перезапускаются. Полное обновление также применяет исправление, но сначала выполняет обычное обновление основного стека. DB и AI не должны удерживаться другой незавершённой операцией.

Серверная резервная копия AI включает документы. Автоматический откат и включение документов AI в существующий экспорт `.pcbackup` не реализованы. Версии Manager и стека независимы.
