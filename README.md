# ProdCast releases

Единая точка получения готовых пакетов ProdCast: **[последний опубликованный комплект](https://github.com/saatchi190499/prodcast-release/releases/latest)** · [все версии](https://github.com/saatchi190499/prodcast-release/releases).

Для установки скачайте `ProdCast-<VERSION>-complete.zip` из выбранного релиза. Manager входит в комплект. Точная версия Manager, состав приложений, ссылки на дополнительные AI-компоненты и SHA256 `release-manifest.json` указаны в описании выбранного релиза. Автоматические GitHub **Source code (zip/tar.gz)** не являются установочным комплектом.

## Как устроен выпуск

1. Код, теги, тесты и сборка остаются в `prodcast-app`, `prodcast-agent`, `prodcast-ai` и `prodcast-worker`.
2. Сначала **Prepare release draft** создаёт общий черновик. Тег компонента `vX.Y.Z-rc.N` передаёт проверенный пакет в общий **черновик `vX.Y.Z` здесь**. В исходном репозитории новый Release не создаётся.
3. Проверенный план фиксирует базовый комплект, новые компоненты и их контрольные суммы. Неизменённые приложения, Manager и инфраструктура переиспользуются из базы без пересборки.
4. **Assemble complete release** собирает ZIP и манифест для Manager. Комплект остаётся черновиком. После сохранения входных пакетов в GitHub Actions на 7 дней их дубликаты автоматически удаляются из Assets.
5. После проверки установки/обновления **Publish approved release** публикует именно проверенный ZIP по SHA256 манифеста. Повторной сборки нет.

Версия комплекта и версии его компонентов могут отличаться. `release-manifest.json` — источник точных версий, исходных коммитов, образов и контрольных сумм. Четыре приложения обязательны; License сохраняется из базового комплекта, если он там есть. Репозиторий `prodcast-license` и его выпуск этой схемой не меняются.

[Инструкция по подготовке и публикации](docs/publishing.md). Исторические релизы в отдельных репозиториях остаются доступными. Опубликованные пакеты не перезаписываются.

## Исходники Manager

Исходники **ProdCast Manager 0.5** находятся в [`prodcast-manager/`](prodcast-manager/), включая тесты, зависимости и `build.ps1`. Это точная копия `source.zip` из выпущенного пакета Manager 0.5. Инструкции по сборке и контрольная сумма исходного архива: [README](prodcast-manager/README.md).

## Установка

Используйте инструкции **внутри выбранного комплекта**, а не инструкцию от другой версии. Для необязательного AI могут требоваться отдельный Ollama archive и файл модели — ссылки и проверки приведены в релизе. ОС, оборудование, сетевые настройки, TLS и уникальные секреты площадки настраиваются отдельно. Данные и пароли действующей площадки не входят в поставку.

Core Python поставляется в bytecode и допускает восстановление кода; браузерный JavaScript и open-source plugins доступны для анализа. Формат поставки не является шифрованием исходников.
